# 광맥전선 (kjh월드 RTS)

브라우저 RTS. 외부 그림·소리 파일 없이 동작한다. 주소: https://rts01.activewith.net

`src/`를 고친 뒤 `node build.js`를 실행하면 맨 위 `index.html`이 다시 만들어진다. GitHub Pages는 이 `index.html`을 서비스한다.

## 경제 규칙
- 일꾼 채취는 유지하고, 회사 4곳(광석 2, 에테르 2)에 광석으로 투자한다. 회사당 100주를 나와 AI가 공유한다.
- 주가는 공정가치로 회귀하는 무작위 변동을 따른다. 주당 0.8%의 매매 충격이 있고 매도 수수료는 3%다.
- 배당은 30초마다 실적에 비례해 지급하며, 회사 자원으로 받는다.
- 51주 이상이면 경영권을 얻어 거점이 내 소속이 된다. 지배 주주 배당 1.5배, 소수 주주 0.5배. 거점이 내 소속이면 상대가 자동 공격 대상으로 삼는다.
- 거점을 공격하면 주가가 내리고, 체력이 0이 되면 40초간 가동 중단(배당 없음, 실적 -25%)된다. 거점은 파괴되지 않으며 승패 계산에서 제외된다.
- 45초 이후 40~80초마다 시장 사건이 발생한다. 회사와 사건은 `companies`, `marketEvents`에 데이터로 추가한다. 거점 위치는 맵의 `sites`(대칭 복제).

## 자유상단(중립 진영)
- 플레이어가 고르는 진영이 아니다. 지부 4곳이 맵의 `posts` 위치에 게임마다 무작위로 배치된다.
- 유닛이 9타일 안에 가면 발견된다. 발견 전에는 거래·동맹 불가, 화면과 미니맵에도 표시되지 않는다.
- 최초 발견자는 광석 100과 수락 확률 +15%를 받는다.
- 동맹 신청 조건은 지부마다 다르다(`branches[].check`). 조건 충족 후 동맹금 100~600을 건다.
- 수락 확률 = 지부 기본값 + 동맹금 비례 최대 50% + 최초 발견 15% + 거절 누적 신뢰(회당 5%, 최대 25%), 상한 90%.
- 거절: 동맹금 소멸, 45초 재신청 대기. 수락: 동맹금이 출자금이 되어 30초마다 6%를 광석으로 돌려받는다.
- 한 지부는 한 진영만 동맹할 수 있다. 상대 동맹 지부를 파괴하면 동맹과 출자금이 사라지고 60초 뒤 다시 열린다.
- 발견한 지부에서는 광석과 에테르를 수수료 20%(동맹 10%, 남풍상회 2%)로 교환한다. 시세는 회사 실적에서 나온다.
- 수레는 동맹 지부에서 내 본진으로 이동하며 적이 파괴할 수 있다.

## 왕초보 모드
- 상대 AI 난이도에서 `왕초보`를 고르면 적용된다(`difficulties.beginner`).
- 전장의 안개 설정과 관계없이 맵 전체가 보인다(`reveal`).
- 사람 플레이어 본진 둘레에 완공된 방어탑(개척단 방어포탑, 철갑회 감시포)이 5~10개 무작위로 놓인다(`towers`, 진영의 `defense`). 맵 중앙 쪽부터 채우고 광맥·분출구와 일꾼 동선은 비운다.
- AI는 쉬움보다 수입·공격 규모가 낮고 첫 공격이 늦다(8분).
- 방어탑도 완공 건물로 세므로 철로조합 동맹 조건(완공 건물 5개)이 시작부터 충족된다.

## 풍선 도움말
- 전장의 유닛·건물·자원·회사 거점·지부에 마우스를 0.35초 올리면(터치는 0.5초 길게 누르면) 도움말이 뜬다. 길게 누른 뒤 손을 떼도 명령은 나가지 않는다.
- 내용: 이름, 종류·소속, 체력·공격·사거리·방어·속도(연구 반영값), 비용·보급·시간, 필요 건물·연구(✓/✗), 만드는 법(단축키 경로), 생산·건설·연구 목록과 각 비용·조건, 능력.
- 명령 카드 버튼 위 도움말도 같은 내용을 쓴다. 상대 유닛은 능력치만 보인다. 내용은 `entities`·`upgrades`·`abilities` 데이터에서 자동으로 만들므로, 콘텐츠를 추가하면 도움말도 따라 바뀐다(`tipHTML`, `src/ui/app.js`).

## 설정 메뉴
- 항목 정의는 `src/data/settings.js`. 항목을 추가하면 메뉴에 자동으로 나타나고, 코드에서는 `RTS.cfg(G).키`로 읽는다.
- 값은 브라우저에 저장되고 나와 AI에 똑같이 적용된다. 게임 중 변경은 일시정지 상태에서 즉시 적용되며, `startOnly` 항목만 다음 판부터 적용된다.
- 묶음 설정은 `RTS.PRESETS`(기본, 안정, 투기장, 총력전).
- 기지 전투 피해(`src/engine/war.js`): 사령부 반경 14타일이 한 기지다. 건물·일꾼 피해액 = 잃은 가치 × 등급(본진 150%, 위성 100%) × (1 + 자원 가중). 그 결과 해당 기지 채취 효율, 진영 신용(배당 배율), 증시가 내려가고, 맞은 자원의 회사 실적과 공격자 약탈이 오른다.
- 사령부 전부 상실(`RTS.warFall`): 한 진영의 완공된 사령부가 모두 파괴되면 증시 하락, 패전 진영 지분 강제 매각, 광석 회사 재건 특수, 자유상단 동맹 해제가 순서대로 적용된다.

## 확장 방법
- 유닛 추가: `entities`에 항목 추가 후 건물의 `trains`에 id 추가. 그림은 기존 `art` 재사용 또는 `RTS.art.units`에 함수 추가. 아이콘은 자동 생성.
- 건물 추가: `entities`에 `kind:'building'`, 일꾼의 `builds`에 id 추가.
- 업그레이드: `upgrades`에 `effects:[{tag|id, stat, add|mul}]` 추가 후 건물의 `researches`에 id 추가.
- 능력: `abilities`에 `use(G,u,c)`와 선택적으로 `ai(G,u)` 추가 후 유닛 `abilities`에 id 추가.
- 진영: `factions`에 hq/worker/supply/defense와 `ai` 블록 추가. 메뉴에 자동 표시.
- 맵: `maps`에 기지·암벽·통로 좌표 추가. 메뉴에 자동 표시. 다른 생성 방식은 `mapgens`에 함수 추가.
- 지부: `branches`에 조건 `check`, 혜택 `perk`(caravan, spread, divBonus, supply, mercs) 추가. 맵 `posts` 칸 수만큼 배치된다.
- 새 규칙: `RTS.addSystem({id,run},{before:'movement'})`.
- 새 유닛 명령: `RTS.orders.이름 = (G,u,o)=>{}`.
- 새 플레이어 입력: `RTS.commands.이름 = (G,team,cmd)=>{}`.

## 둘이 대전
- 시작 화면 **둘이 대전** → 한 기기는 **방 만들기**(4자리 번호 표시), 다른 기기는 번호를 넣고 **참가**.
- 방장이 전장, 자기 진영(상대는 다른 진영), 팀별 핸디캡을 고르고 **시작**한다. 게임 규칙은 방장 기기의 설정값을 쓴다.
- 연결: WebRTC(PeerJS 1.5.4, unpkg에서 '둘이 대전'을 누를 때만 불러온다). 처음 연결을 이어 줄 때만 PeerJS 공용 서버를 쓰고, 게임 데이터는 두 기기가 직접 주고받는다. 그래서 연결할 때 인터넷이 되어야 한다.
- 동기화: lockstep(`src/engine/net.js`). 2틱(0.1초)이 한 턴이고, 내 입력은 3턴 뒤에 양쪽 기기에서 같이 실행된다(지연 약 0.15~0.25초). 상대 입력이 아직 안 왔으면 기다리며 '상대 기기를 기다리는 중'을 띄운다.
- 25턴마다 상태 해시를 비교해 어긋나면 알린다. 같은 V8 엔진(Chrome, 삼성 인터넷, Edge)끼리 쓴다. Firefox·Safari와 섞으면 계산이 어긋날 수 있다.
- 대전 중: 1배속 고정, 일시정지는 양쪽 공통, 설정 메뉴는 화면·소리만 바꿀 수 있고 게임은 멈추지 않는다, 저장·이어하기 없음. 한쪽이 나가거나 연결이 끊기면 대전 중단 화면이 뜬다. 다시 하려면 방을 새로 만든다.
- 핸디캡 단계는 `RTS.HANDICAPS`(`src/data/settings.js`): 시작 광석·에테르, 채취 수입 배율, 완공 방어탑, 해당 팀만 맵 공개.
- 플레이어 입력은 모두 `send()` → (혼자) `RTS.command()` / (둘이) `Lockstep.local()`을 거친다. 시뮬레이션 코드에서 `Math.random()`, 시간 함수, 화면 상태를 읽으면 두 기기가 어긋난다. `node test/net.js`로 확인한다.

```js
g.destroy();
```
