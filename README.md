# 광맥전선 (kjh월드 RTS)

브라우저 RTS. 외부 그림·소리 파일 없이 동작한다. 주소: https://rts01.activewith.net

`src/`를 고친 뒤 `node build.js`를 실행하면 맨 위 `index.html`이 다시 만들어진다. GitHub Pages는 이 `index.html`을 서비스한다.

## 경제 규칙
- 일꾼 채취는 유지하고, 회사 4곳(광석 2, 에테르 2)에 광석으로 투자한다. 회사당 100주를 나와 AI가 공유한다.
- 주가는 공정가치로 회귀하는 무작위 변동을 따른다. 주당 0.8%의 매매 충격이 있고 매도 수수료는 3%다.
- 배당은 30초마다 실적에 비례해 지급하며, 회사 자원으로 받는다.
- 51주 이상이면 경영권을 얻어 거점이 내 소속이 된다. 지배 주주 배당 1.5배, 소수 주주 0.5배. 거점이 내 소속이면 상대가 자동 공격 대상으로 삼는다.
- 거점을 공격하면 주가가 내리고, 체력이 0이 되면 40초간 가동 중단(배당 없음, 실적 -25%)된다. 거점은 파괴되지 않으며 승패 계산에서 제외된다.
- 45초 이후 40~80초마다 시장 사건이 발생한다. 회사와 사건은 `companies`, `marketEvents`에 데이터로 추가한다. 거점 위치는 맵의 `sites`(대칭 복제).

## 자유상단(중립 진영)
- 플레이어가 고르는 진영이 아니다. 지부 4곳이 맵의 `posts` 위치에 게임마다 무작위로 배치된다.
- 유닛이 9타일 안에 가면 발견된다. 발견 전에는 거래·동맹 불가, 화면과 미니맵에도 표시되지 않는다.
- 최초 발견자는 광석 100과 수락 확률 +15%를 받는다.
- 동맹 신청 조건은 지부마다 다르다(`branches[].check`). 조건 충족 후 동맹금 100~600을 건다.
- 수락 확률 = 지부 기본값 + 동맹금 비례 최대 50% + 최초 발견 15% + 거절 누적 신뢰(회당 5%, 최대 25%), 상한 90%.
- 거절: 동맹금 소멸, 45초 재신청 대기. 수락: 동맹금이 출자금이 되어 30초마다 6%를 광석으로 돌려받는다.
- 한 지부는 한 진영만 동맹할 수 있다. 상대 동맹 지부를 파괴하면 동맹과 출자금이 사라지고 60초 뒤 다시 열린다.
- 발견한 지부에서는 광석과 에테르를 수수료 20%(동맹 10%, 남풍상회 2%)로 교환한다. 시세는 회사 실적에서 나온다.
- 수레는 동맹 지부에서 내 본진으로 이동하며 적이 파괴할 수 있다.

## 잿빛 부족(AI 중립 세력)
- 자유상단과 별개인 세력이다. 팀 번호는 `RTS.TRIBE`(-2)이고 스스로 병력을 뽑고 움직인다. 회당 1, 망루 2, 시작 병력 4(전사·궁수)로 시작해 20초마다 1기씩 최대 10기까지 보충한다.
- 위치는 게임마다 무작위(`RTS.tribeSpotPick`). 맵 가운데 12칸, 시작 기지 20칸, 확장 기지 11칸, 자원·회사 거점·지부 근처는 피하고 두 시작 기지에서 걸어서 닿는 곳만 고른다. 그래서 한쪽에 더 가까울 수 있다. 망루 2개는 회당 양쪽 무작위 방향.
- 관계는 플레이어마다 따로다: 중립 · 동맹 · 적대. 판정은 `RTS.foe(G,a,b)` 하나로 하며 자동 공격, 범위 피해, 시야가 모두 이것을 따른다. 중립이면 서로 공격하지 않고 범위 피해도 들어가지 않는다.
- 발견: 내 유닛·건물 시야에 회당이 들어오면. 발견 후 왼쪽 위에 부족 패널(관계, 미션 진행도)이 뜬다.
- 외교: 공병(일꾼)을 선택하고 회당을 우클릭하면 공병이 걸어가서 미션 2개를 받는다(`tribeMissions`에서 무작위). 2개 성공 동맹, 1개 중립(60초 뒤 재시도), 0개 적대. 부족은 한 진영과만 동맹한다.
- 미션 7종: 광석 공물 250, 에테르 공물 100, 회당 경비(전투 유닛 4기 20초), 침입자 토벌(4개 파괴), 정찰 의뢰(표시 지점 방문), 교역로 건설(건물 2개 완공), 병력 과시(전투 유닛 8기). 미션 추가는 `need`·`prog`·`time`(+`start`·`tick`·`pay`)만 쓰면 된다.
- 동맹: 내가 공격받으면 25초에 한 번 판정해 50% 확률로 지원군(최대 6기, 회당 경비 2기는 남김)을 보낸다. 지원하는 45초 동안은 공격자와 부족이 서로 적이다. 부족 시야를 공유한다.
- 적대: 60초 뒤부터 110~150초마다 경비 2기를 뺀 병력이 가장 가까운 내 건물을 습격한다.
- 공격: 중립·동맹 부족을 우클릭하면 경고가 뜨고, 3초 안에 한 번 더 누르면 공격한다. 공격하면 즉시 적대(동맹이면 배신).
- 회당이 무너지면 무너뜨린 쪽이 광석 250을 얻고, 외교와 병력 보충이 끝난다. 남은 병력·망루는 그대로 있다.
- 상대 AI: 부족을 찾으면 70% 확률로 동맹을 노려 공병을 보내고, 회당 경비·정찰 미션에는 병력을 보낸다. 적대한 부족의 습격은 위협으로 인식해 막는다.
- 수치는 `RTS.TRIBE_RULES`(`src/engine/tribe.js`).

## 왕초보 모드
- 상대 AI 난이도에서 `왕초보`를 고르면 적용된다(`difficulties.beginner`).
- 전장의 안개 설정과 관계없이 맵 전체가 보인다(`reveal`).
- 사람 플레이어 본진 둘레에 완공된 방어탑(개척단 방어포탑, 철갑회 감시포)이 5~10개 무작위로 놓인다(`towers`, 진영의 `defense`). 맵 중앙 쪽부터 채우고 광맥·분출구와 일꾼 동선은 비운다.
- AI는 쉬움보다 수입·공격 규모가 낮고 첫 공격이 늦다(12분).

## AI 난이도
- 2026-11에 모든 단계를 두 단계씩 낮췄다. 어려움 = 예전 쉬움, 보통 = 예전 왕초보, 쉬움·왕초보는 그보다 더 약하다.
- 첫 공격: 왕초보 12분, 쉬움 10분, 보통 8분, 어려움 5분 30초. 수입 배율: 0.4 / 0.5 / 0.6 / 0.8. 수치는 `difficulties`(`src/data/content.js`).
- 방어탑도 완공 건물로 세므로 철로조합 동맹 조건(완공 건물 5개)이 시작부터 충족된다.

## 풍선 도움말
- 전장의 유닛·건물·자원·회사 거점·지부에 마우스를 0.35초 올리면(터치는 0.5초 길게 누르면) 도움말이 뜬다. 길게 누른 뒤 손을 떼도 명령은 나가지 않는다.
- 내용: 이름, 종류·소속, 체력·공격·사거리·방어·속도(연구 반영값), 비용·보급·시간, 필요 건물·연구(✓/✗), 만드는 법(단축키 경로), 생산·건설·연구 목록과 각 비용·조건, 능력.
- 명령 카드 버튼 위 도움말도 같은 내용을 쓴다. 상대 유닛은 능력치만 보인다. 내용은 `entities`·`upgrades`·`abilities` 데이터에서 자동으로 만들므로, 콘텐츠를 추가하면 도움말도 따라 바뀐다(`tipHTML`, `src/ui/app.js`).

## 설정 메뉴
- 항목 정의는 `src/data/settings.js`. 항목을 추가하면 메뉴에 자동으로 나타나고, 코드에서는 `RTS.cfg(G).키`로 읽는다.
- 값은 브라우저에 저장되고 나와 AI에 똑같이 적용된다. 게임 중 변경은 일시정지 상태에서 즉시 적용되며, `startOnly` 항목만 다음 판부터 적용된다.
- 묶음 설정은 `RTS.PRESETS`(기본, 안정, 투기장, 총력전).
- 기지 전투 피해(`src/engine/war.js`): 사령부 반경 14타일이 한 기지다. 건물·일꾼 피해액 = 잃은 가치 × 등급(본진 150%, 위성 100%) × (1 + 자원 가중). 그 결과 해당 기지 채취 효율, 진영 신용(배당 배율), 증시가 내려가고, 맞은 자원의 회사 실적과 공격자 약탈이 오른다.
- 사령부 전부 상실(`RTS.warFall`): 한 진영의 완공된 사령부가 모두 파괴되면 증시 하락, 패전 진영 지분 강제 매각, 광석 회사 재건 특수, 자유상단 동맹 해제가 순서대로 적용된다.

## 고급 그래픽(WebGL)
- 설정 '화면과 소리' → **고급 그래픽**(기본 켬). 전장을 화면 밖 2D 캔버스(`world`)에 그린 뒤 `src/ui/glfx.js`가 WebGL로 합성해 아래 캔버스에 낸다. 체력 바·건설 미리보기·드래그 상자·핑은 원래 캔버스(투명, 맨 위)에 그려 조명·안개를 받지 않는다. 입력도 원래 캔버스가 받는다.
- 단계: ① 빛 지도(절반 크기) = 테마 주변광 + 빛마다 부드러운 원을 더함 ② 밝은 부분 추출 → 가로·세로 흐림 2회(4분의 1 크기) = 빛 번짐 ③ 최종: 장면 × 빛 지도, 밝은 색은 스스로 빛나게 유지, 구름 그림자, 빛 번짐, 안개, 색 보정·비네트·필름 입자, 충격파 굴절(최대 6개).
- 빛은 `render.js`의 `light(x, y, 반경, [r,g,b], 세기)`로 넣는다(월드 px). 지금 넣는 곳: 유닛(팀 색), 비행체 엔진, 건물(팀 색, 본진 더 밝게), 추출기, 부족 화톳불, 불타는 건물, 공사 중 건물, 광맥·분출구, 예광탄·포탄, 총구 섬광, 착탄, 화구, 건물 폭발 섬광, 불, 불씨, 치료 광선, 광맥 반짝임.
- 주변광·색조는 테마별 `R.LIGHTING`(`dusk`, `ochre`, `frost`, `moss`). 값이 1보다 작을수록 어둡고 불빛이 도드라진다.
- 안개: 고급 그래픽에서는 타일마다 0(보임)/140(본 적 있음)/255(처음)을 텍스처로 올리고 셰이더가 부드럽게 보간한다. 처음 보는 곳에는 움직이는 구름 무늬, 본 적 있는 곳은 어둡고 채도를 뺀다. 3프레임마다 갱신.
- 느린 기기: 프레임 간격 40ms 초과가 오래 이어지면 빛 번짐과 구름 그림자를 끈다(`gfx.low`, 한 번 알림). WebGL이 없거나 컨텍스트를 잃으면 예전 2D 그리기로 돌아간다.
- 설정: **구름 그림자**, **날씨 입자**(눈·모래 먼지·떠다니는 빛가루·포자, '화려한 특수 효과'가 켜져 있어야 보인다). 모두 이 브라우저 전용(`client`)이라 게임 계산과 무관하다.

## 저사양 모드·프레임 수

## 둘이 대전
- 시작 화면 **둘이 하기** → 한 기기는 **방 만들기**(4자리 번호 표시), 다른 기기는 번호를 넣고 **참가**.
- 방장이 전장, 자기 진영(상대는 다른 진영), 팀별 핸디캡을 고르고 **시작**한다. 게임 규칙은 방장 기기의 설정값을 쓴다.
- 연결: WebRTC(PeerJS 1.5.4, unpkg에서 '둘이 대전'을 누를 때만 불러온다). 처음 연결을 이어 줄 때만 PeerJS 공용 서버를 쓰고, 게임 데이터는 두 기기가 직접 주고받는다. 그래서 연결할 때 인터넷이 되어야 한다.
- 동기화: lockstep(`src/engine/net.js`). 2틱(0.1초)이 한 턴이고, 내 입력은 3턴 뒤에 양쪽 기기에서 같이 실행된다(지연 약 0.15~0.25초). 상대 입력이 아직 안 왔으면 기다리며 '상대 기기를 기다리는 중'을 띄운다.
- 25턴마다 상태 해시를 비교해 어긋나면 알린다. 같은 V8 엔진(Chrome, 삼성 인터넷, Edge)끼리 쓴다. Firefox·Safari와 섞으면 계산이 어긋날 수 있다.
- 대전 중: 1배속 고정, 일시정지는 양쪽 공통, 설정 메뉴는 화면·소리만 바꿀 수 있고 게임은 멈추지 않는다, 저장·이어하기 없음. 한쪽이 나가거나 연결이 끊기면 대전 중단 화면이 뜬다. 다시 하려면 방을 새로 만든다.
- 핸디캡 단계는 `RTS.HANDICAPS`(`src/data/settings.js`): 시작 광석·에테르, 채취 수입 배율, 완공 방어탑, 해당 팀만 맵 공개.
- 플레이어 입력은 모두 `send()` → (혼자) `RTS.command()` / (둘이) `Lockstep.local()`을 거친다. 시뮬레이션 코드에서 `Math.random()`, 시간 함수, 화면 상태를 읽으면 두 기기가 어긋난다. `node test/net.js`로 확인한다.

## 둘이 하기: 중립세력
- 두 사람은 서로 다른 진영을 고른다. 남은 진영이 중립세력(2번 팀 AI)이 되고, 두 방식 모두에 나온다(`RTS.restFaction`, `RTS.netGameOpts`). 방장이 상대 진영도 고르며, 방장 진영과 같은 것을 고르면 서로 바뀐다.
- 강도: 보통 AI 대비 100·115·**130(기본)**·150·170%. 배율 k는 수입 ×k, 일꾼 상한·공격 규모 ×k, 판단 주기·첫 공격·확장·투자 간격 ÷k로 적용된다(`RTS.aiDiff`, `src/engine/ai.js`). 기본값은 `RTS.COOP`(`src/engine/net.js`).
- 적이 여럿이면 AI는 공격할 때마다 대상 팀을 번갈아 정한다(`aiState.tgt`).
- 균형(헤드리스, 보통 AI 둘이 사람 역할, 진영 조합 3 × 맵 4 = 12판): 협동 130% 사람 편 8승 4패, 170% 1승 11패. 대전 130%는 중립세력이 7판, 사람 중 하나가 5판 승리.

### 둘이 협동
- 대기실 방식 **둘이 협동**(마지막 선택을 기억). 두 사람은 같은 편(`side` 0): 서로 피해 없음(`RTS.ally`, `RTS.foe`, `RTS.damage`), 시야 공유, 동료에게 공격 명령 불가.
- 시작 위치: 방장 = 시작 기지 0, 동료 = 시작 기지 0에서 가장 가까운 확장 기지(광맥 6), 중립세력 = 시작 기지 1(`RTS.coopBases`).
- 승패는 편 단위. 중립세력 전멸 시 승리, 두 사람 모두 전멸 시 패배. 한 사람만 전멸하면 패배 화면이 뜨고 관전으로 남는다(게임은 계속).
- 색: 나 파랑, 동료 보라, 중립세력 주황(`RTS.COOP_COLOR`). 동료 선택 테두리 하늘색. 거래소·도움말은 지분을 나/동료/상대로 나눠 보인다.

### 서로 대전(셋이 싸움)
- 두 사람과 중립세력이 모두 서로 적이다. 마지막까지 남는 팀이 승리한다. 먼저 전멸한 사람은 패배 화면 뒤 **관전 계속**으로 남는다(두 기기 계산이 이어져야 하므로 게임은 멈추지 않는다).
- 중립세력 위치: 두 시작 기지와의 거리 차이가 가장 작은 확장 기지, 같은 점수면 무작위(`RTS.ffaBases`). 쌍둥이 능선·거울 호수는 차이 0, 빙원 십자로 9칸, 협곡 회랑 26칸(4곳이 같은 점수라 무작위로 어느 한쪽에 가깝다).

## 대전 채팅·음성·버전 확인
- **버전**: `node build.js`가 소스 해시 7자리를 `RTS.BUILD`로 넣는다. 시작 화면 아래에 표시된다. 대기실에서 두 기기의 버전이 다르면 경고하고 방장의 시작 버튼을 잠근다(버전이 다르면 계산이 어긋난다).
- **문자 채팅**: 대기실 아래 '대화', 게임 중에는 Enter 또는 상단 **채팅** 버튼. 빠른 문구 버튼(`QUICK`, `src/ui/app.js`). 메시지는 lockstep을 거치지 않고 연결로 바로 보내므로 게임 계산에 영향이 없다. 최대 80자.
- **음성 채팅**: **음성 켜기**를 누르면 내 마이크를 상대에게 한 방향 통화(PeerJS `call`)로 보낸다. 두 사람이 각자 켜고 끈다. 메아리 제거·잡음 억제를 켜지만, 같은 방에서는 되울림이 날 수 있으니 이어폰을 쓴다. 상대 음성이 들어오는 동안 배경음악을 40%로 줄인다. 설정 '상대 음성 크기'로 조절.
- 브라우저가 소리 자동 재생을 막으면 '화면을 한 번 누르면 상대 음성이 들립니다'가 뜨고, 다음 터치에 재생한다.

## 배경음악
- 외부 파일 없이 합성한다. 메뉴·대기실·결과 화면은 `menu` 곡, 게임 중에는 `game` 곡.
- `game` 곡은 긴장도(0~1)에 따라 킥, 스네어, 16분 아르페지오가 더해진다. 긴장도는 내 유닛·건물이 맞거나 내 유닛이 공격하면 오르고 서서히 내려간다. 시간이 지나면 기본값이 최대 0.3까지 오른다.
- 설정 '배경음악 크기'(기본 50%, 0이면 끔). 상단 **소리 끔**은 효과음과 음악을 모두 끈다(상대 음성은 그대로).
- 곡 추가: `RTS.MUSIC_SONGS`에 bpm, 화음(`chords`), 베이스, 아르페지오 패턴을 넣고 `RTS.Music().setMode(이름)`.
